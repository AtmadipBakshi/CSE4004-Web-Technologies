# Lab-12: Node.js Advanced (Express & MongoDB)

## Exercises

### Exercise 1: REST API
- CRUD operations using Express

### Exercise 2: Middleware
- Logging middleware
- Route-level middleware

### Exercise 3: MongoDB
- CRUD with Mongoose
- Database connection

## Run Instructions

### Install dependencies:
npm install

### Run Exercise 1:
node ex1-api/server.js

### Run Exercise 2:
node ex2-middleware/app.js

### Run Exercise 3:
node ex3-mongodb/app.js
